SUIVI PARAGE V3.2

Nouveautés principales :
- estimation automatique des kilomètres routiers à partir des adresses des chantiers filtrés ;
- calcul par journée, dans l’ordre des heures de début ;
- départ paramétrable et retour au point de départ activable ;
- durée de route estimée ;
- détail de chaque étape de la tournée ;
- kilométrage manuel toujours prioritaire si l’utilisateur le modifie ;
- calcul du coût kilométrique, du résultat, du CA/km et du CA/heure de route ;
- tableaux mensuels techniques et économiques ;
- cache local des coordonnées pour limiter les appels réseau ;
- fonctionnement hors connexion conservé : la dernière estimation reste disponible.

L’estimation nécessite Internet et utilise :
- API Adresse (adresse.data.gouv.fr) pour localiser les adresses françaises ;
- OSRM public pour l’estimation routière.

Les résultats sont indicatifs et peuvent être corrigés manuellement.
