SUIVI PARAGE — V4.0 PRODUCTION

Nouveautés principales :
- ajout de photos par pied depuis l'appareil photo ou la galerie ;
- compression automatique des photos avant sauvegarde ;
- conservation locale hors connexion puis synchronisation dans la sauvegarde Supabase ;
- journal d'activité réservé à l'administratrice ;
- export CSV du journal ;
- version affichée v4.0 et nouveau cache applicatif.

PHOTOS
Dans la fiche d'un bovin, chaque pied possède un bouton « Photo du pied ».
Les miniatures sont visibles sous le pied. Appuyer sur une miniature pour l'agrandir.
Le bouton × supprime uniquement la photo concernée.

IMPORTANT
Les photos augmentent le volume de la sauvegarde. Il est recommandé de conserver uniquement les photos utiles et d'effectuer régulièrement une sauvegarde manuelle JSON.

INSTALLATION
Remplacer tout le contenu du dépôt GitHub par le contenu de ce dossier en conservant la même URL.
Fermer et rouvrir l'application. Sur iPhone, supprimer/recréer le raccourci uniquement si l'ancienne icône ou l'ancien cache persiste.
