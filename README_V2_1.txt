SUIVI PARAGE V2.1

MISE A JOUR GITHUB
1. Supprimer les anciens fichiers du dépôt (conserver uniquement ce qui est utile hors application).
2. Décompresser ce ZIP.
3. Envoyer tout le contenu du dossier Application_Parage_V2_1 à la racine du dépôt.
4. Attendre 1 à 3 minutes puis actualiser avec Ctrl+F5.

IPHONE / IPAD
- Pour remplacer l'ancienne icône, supprimer l'ancien raccourci Parage de l'écran d'accueil.
- Ouvrir l'application dans Safari, Partager, puis Sur l'écran d'accueil.
- La nouvelle icône limousine apparaîtra.
