Suivi Parage V4.0.20

Correctif PWA iPhone/iPad :
- nouvelle identité PWA stable pour sortir des anciennes installations bloquées en V4.0.15 ;
- nettoyage automatique, une seule fois, des anciens caches et anciens service workers de Parage ;
- conservation des données locales et des paramètres Supabase (localStorage non effacé) ;
- URLs des ressources versionnées ;
- vérification réseau prioritaire pour les nouvelles versions.

IMPORTANT : après publication de cette version sur GitHub, supprimer UNE DERNIERE FOIS l'ancienne icône Parage puis ajouter à l'écran d'accueil depuis la page Safari affichant V4.0.20. Les versions suivantes devront conserver le même manifest id : suivi-parage-gds3265-v2.
