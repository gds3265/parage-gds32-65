SUIVI PARAGE V3.1.1 — STABILISATION TERRAIN

Corrections principales :
- Nouveau chantier : date du jour et heure de début systématiquement renseignées.
- Heure de fin automatique à la validation.
- Pro forma A4 restructurée et plus lisible.
- Retour depuis la pro forma : confirmation puis retour à l’accueil.
- Bouton Pro forma de l’onglet Comptabilité réparé : régénération depuis les données du chantier.
- Filtres des bilans cumulés : chaque critère restreint le même jeu de résultats.
- Version du cache mise à jour pour forcer le chargement des fichiers corrigés.

INSTALLATION
1. Remplacer tout le contenu du dépôt GitHub par les fichiers de ce dossier.
2. Attendre la fin du déploiement GitHub Pages.
3. Sur ordinateur : Ctrl + F5.
4. Sur iPhone/tablette : fermer l’application, supprimer l’ancien raccourci si nécessaire, ouvrir le site dans Safari puis l’ajouter de nouveau à l’écran d’accueil.
