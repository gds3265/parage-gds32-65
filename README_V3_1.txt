SUIVI PARAGE V3.1

Nouveautés :
- Bilans technique et économique séparés.
- Filtres combinables : dates, département, race, catégorie, problème, soin, exploitation et commune.
- Export CSV du résultat filtré.
- Coût de tournée : point de départ par défaut Pontis-de-Rivière (31), kilomètres saisis, coût/km, péages et autres frais.
- Indicateurs économiques : CA, facturé, encaissé, reste dû, coût tournée et résultat simplifié.
- Tous les rôles autorisés peuvent consulter les deux bilans ; les droits de modification restent inchangés.

INSTALLATION
Remplacer tous les fichiers de la version précédente sur GitHub par ceux de ce dossier.
Conserver la configuration Supabase déjà saisie sur chaque appareil.
Sur iPhone, fermer puis rouvrir l’application ; si nécessaire supprimer puis recréer le raccourci pour vider le cache.
