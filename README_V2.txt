SUIVI PARAGE V2.0

MISE À JOUR GITHUB PAGES
1. Supprimer/remplacer les anciens fichiers de l’application.
2. Envoyer TOUS les fichiers et dossiers contenus dans ce dossier, notamment :
   - app-logo.png
   - icon-192.png
   - icon-512.png
   - apple-touch-icon.png
   - favicon.png
   - assets/logo-gds.png
3. Attendre 1 à 3 minutes, puis actualiser la page.
4. Sur iPhone : supprimer l’ancien raccourci de l’écran d’accueil, ouvrir le site dans Safari, puis Partager > Sur l’écran d’accueil > Ajouter. iOS conserve parfois l’ancienne icône tant que le raccourci n’est pas supprimé.

FONCTIONNEMENT HORS LIGNE
- Chaque saisie est d’abord enregistrée localement.
- Sans réseau, le bandeau indique « Hors ligne · enregistré localement ».
- Dès que le réseau revient, l’application essaie automatiquement d’envoyer la sauvegarde à Supabase.
- Les boutons d’export JSON, Excel et ZIP restent disponibles comme solution de secours.

SUPABASE
L’URL et la clé publique restent enregistrées uniquement sur l’appareil dans les paramètres de l’application.
