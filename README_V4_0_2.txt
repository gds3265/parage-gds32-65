SUIVI PARAGE V4.0.2 — IMPORT HISTORIQUE 2025-2026

Cette version intègre automatiquement 491 lignes du fichier « FICHIER DE SUIVI PARAGE 1.xlsx ».

- 256 chantiers de 2025 et 235 chantiers de 2026, soit 491 lignes historiques.
- Les doublons sont ignorés lors d'une nouvelle ouverture ou d'une réinstallation.
- Les prix HT et TTC historiques sont verrouillés et ne sont jamais recalculés avec les tarifs actuels.
- Les anciens chantiers alimentent l'historique, les bilans, les statistiques par race/département et le suivi des règlements.
- Le fichier historique ne comportait pas les numéros de travail, les pieds par bovin, les lésions ni les photos : ces données sont indiquées comme non disponibles.
- Dans Paramètres > Historique 2025-2026, le bouton « Contrôler / réintégrer l'historique » vérifie l'import sans créer de doublons.

Après dépôt sur GitHub, attendre la fin du déploiement puis actualiser l'application. Le bandeau doit afficher v4.0.2.
