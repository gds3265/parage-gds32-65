SUIVI PARAGE — VERSION 3.3

NOUVEAUTÉS
- Bandeau supérieur compact sur ordinateur et mobile.
- Numéro de version v3.3 corrigé dans l'application et le cache.
- Bascule Mode Terrain / Mode Bureau.
- Mode Terrain simplifié pour la pareuse : Accueil, Nouveau chantier, Historique et Fichiers.
- Mode Bureau : accès aux modules supplémentaires autorisés par le rôle.
- La pareuse, l'admin et le technicien peuvent changer de mode.
- La comptable ouvre directement l'interface Bureau.
- Les droits restent déterminés par le profil Supabase.
- Les onglets Adresses, Utilisateurs et Paramètres restent réservés à l'admin.

INSTALLATION
1. Remplacer tous les anciens fichiers du dépôt GitHub par le contenu de ce dossier.
2. Attendre la fin du déploiement GitHub Pages.
3. Sur ordinateur : Ctrl + F5.
4. Sur iPhone/tablette : fermer complètement l'application et la rouvrir.
5. Si l'ancienne version persiste, supprimer puis recréer le raccourci d'écran d'accueil.

Aucun nouveau script SQL n'est nécessaire si la V3 Supabase est déjà installée.
