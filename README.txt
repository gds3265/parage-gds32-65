APPLICATION SUIVI PARAGE - VERSION 1

1. Décompresser le ZIP.
2. Pour tester sur le PC : lancer un petit serveur web dans ce dossier (l'application ne doit pas être ouverte directement en file:// pour charger la base clients).
3. Pour la mettre en ligne : déposer tout le contenu du dossier sur Netlify ou GitHub Pages.
4. Les données sont enregistrées localement dans le navigateur utilisé. Utiliser régulièrement Paramètres > Exporter une sauvegarde.

Fonctions : base de 9 161 élevages, chantier, schéma 4 pieds/8 onglons, lésions/soins, historique, animaux à revoir, pro forma imprimable/PDF, export .xls compatible avec les colonnes du fichier comptable, bilan mensuel et frais.

IMPORTANT : cette V1 conserve les données localement sur l'appareil. La synchronisation multi-utilisateurs/comptable nécessite une future base en ligne sécurisée.


V1.1 : saisie continue du numéro bovin, bouton bovin terminé/suivant, sélection rapide par pied ou paire, calcul par pieds et non par onglons.
